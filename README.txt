秋月电子 · AkiTECH 静态官网

版本：第六版，2026-10-15
完整业务描述：秋月重工私营网络安全顾问与系统承包商

使用方式
将 dist 中的全部内容上传到静态网站目录。index.html 是入口。
无构建步骤，无外部字体、脚本或运行时依赖。
本地建议用任意静态 HTTP 服务器预览。

页面与交互
1. 深蓝黑、银色与标志金色的视觉设计，以原版 SVG Logo 作为首屏主体。
   介绍段随滚动放大原版 Logo，聚焦金色双环，再依次引出六项业务。
   业务节点可点击跳转并展开详情；关闭动效或视口较矮时自动改为静态排版。
2. 原创 Canvas 设备示意：桌面、24 口交换机与配线架、开放式机架。
3. 桌面滚动推进场景，按钮与方向键也可以切换；手机采用按钮切换。
4. 服务项目折叠展开；个人、学校、小型企业场景选项卡。
5. 支持减少动效偏好、动效暂停、移动导航与键盘操作。
6. 页脚可展开法律声明与隐私说明。
7. 设备使用通用造型，不标注工作室厂商品牌，不模拟开机。
8. 随滚动停驻、推近与分段过渡，展示选型配置、网络设计、工程交付。跳线光点仅作信号流向示意。
9. 场景使用分段退场/入场，设备主体预缓存，动态层约 30 帧/秒；离屏及后台停止绘制。

编辑
index.html：主要文案、服务、法律声明和链接。
styles.css：布局、字体、颜色和响应式样式。
app.js：导航、选项卡与动效偏好。
intro.js：原版 Logo 放大、双环承接、业务引线展开与详情跳转。
workbench.js：设备绘制、场景交互与滚动逻辑。
assets：工作室提供的标志及网站图标。

说明
设备为概念造型，不代表真实产品、案例或厂商合作。
法律声明为网站一般说明；实际项目承接主体、授权、数据处理及责任约定需在项目协议中明确。
当前没有联系页面、信息提交表单或第三方统计脚本。
仅在浏览器 localStorage 保存 akitech-motion 动效偏好。
